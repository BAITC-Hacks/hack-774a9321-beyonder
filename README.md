# Beyonder — умный подбор подрядчиков

Решение кейса #79-lite трека 06 HackAlem AI: по условиям мероприятия выбирает до
трёх подрядчиков и объясняет, чем каждый отличается от остальных в подборке.
Каталог организаторов содержит 66 анонимизированных профилей.

## Запуск

Нужен Python 3.10 или новее. Из корня репозитория:

```bash
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --port 8000
```

Откройте http://127.0.0.1:8000. Интерактивная документация API —
http://127.0.0.1:8000/docs. API-ключ для запуска не требуется.
Рекомендуется предварительно создать виртуальное окружение `python -m venv .venv`.
В Windows его интерпретатор — `.venv\Scripts\python.exe`.

## Что реализовано

- Фильтрация по городу, категории, свободной дате, бюджету, формату, языку и длительности.
- Детерминированное ранжирование, максимум три карточки, все причины исключения и подсказки.
- Сравнительные объяснения: разница цен, уникальные языки/форматы, запас по длительности.
- Последовательная воронка `funnel`: пул → свободная дата → бюджет → формат → язык → длительность.
  Неуказанные язык и длительность не добавляют шагов; вне календаря воронка пустая.
- Исходы `found`, `partial`, `none_match`, `no_category_in_city`, `invalid_request`.
- Необязательная редактура объяснений через OpenAI, проверка ответа и локальный кэш.

## OpenAI: необязательный слой объяснений

Скопируйте `.env.example` в `.env`, задайте `OPENAI_API_KEY` и `OPENAI_MODEL`, затем:

```bash
python -m uvicorn app.main:app --port 8000 --env-file .env
```

По умолчанию модель — `gpt-4o-mini`; она должна поддерживать `temperature=0` и
[Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
Переменная `EXPLANATIONS_LLM_ENABLED=false` полностью выключает обращения к API.
Ключ хранится только в окружении или локальном `.env`, который исключён из Git.

Один вызов обрабатывает все карточки. Модель получает только условия запроса,
проверяемые факты, релевантные цитаты и уже рассчитанные кодом сравнения.
Она возвращает JSON с массивом объяснений и не влияет на отбор или порядок.
Проверяются 1–2 предложения, стоп-лист, числовые/цитатные основания, совпадение
сравнения с входом, неизвестные числа/цитаты и различимость без имён.
При нарушении допускается одна попытка исправления с перечнем ошибок.
На обе попытки вместе выделено 6 секунд; автоматические повторы SDK выключены.
Нет ключа, ошибка, таймаут или повторный невалидный ответ — используются шаблоны.

В каждой карточке есть `explanation_source`: `llm` либо `template`.
Старые поля ответа сохранены; добавлены только источник объяснения и воронка.

Кэш — `.cache/explanations.json`, ключ SHA-256 от запроса, упорядоченных ID и версии
промпта. Дополнительно проверяется отпечаток фактов и модель. Успешные тексты и
решение оставить шаблон запоминаются, чтобы одинаковый запрос не менял текст.
Если после временной ошибки нужно снова попробовать LLM, удалите этот файл и
перезапустите приложение. При недоступном диске остаётся кэш в памяти процесса.
Для демонстрации используйте один процесс uvicorn: файловый кэш не синхронизирует
генерацию между несколькими серверными процессами. При изменении входных фактов,
модели, версии промпта или режима LLM объяснения могут обновиться.

## Проверка

```bash
python -m pytest -q
```

Тесты работают без сети: DoD использует шаблоны, LLM-тесты подменяют SDK.
Проверяются все исходы, границы календаря, занятость, смена даты, детерминизм,
различимость карточек, контракт HTTP API, кэш, повторная попытка и общий таймаут.

Сценарии для страницы или `POST /api/match`:

1. Алматы, 23.09.2026, корпоратив, Ведущий, 2 000 000 ₸ — три карточки.
2. Те же условия на 24.09.2026 — другой состав; HK-27222 исключён как занятый.
3. Алматы, 23.09.2026, свадьба, Флорист, 2 000 000 ₸ — две карточки с объяснением неполной выдачи.
4. В первом запросе бюджет 1 ₸ — пустой результат с причинами.
5. Астана, категория Лайв-бэнд — отдельный исход отсутствующей категории.

## Архитектура и данные

`app/data.py` загружает CSV; `app/matcher.py` строит пул, сохраняет причины отказа,
считает рейтинг и сравнения; `app/explain_llm.py` редактирует тексты при наличии
ключа. `app/main.py` предоставляет `GET /api/meta`, `POST /api/match` и страницу
`static/index.html`. Стек: Python, FastAPI, uvicorn, OpenAI SDK, pytest.

Основной источник — `data/hackathon-dataset-anonymized.csv`. Дополнительные профили
можно разместить в `data/synthetic-extra.csv` того же формата с `synthetic=true`;
поле `source` отличает данные команды от данных организаторов. Флаги синтетики,
оценочных цен и восстановленных городов остаются в ответе API.

Календарь известен только с 23.09 по 31.12.2026; цена «от» не является окончательной
сметой. Бронирование и уведомления не реализованы. Качество перефразирования зависит
от выбранной модели; локальная проверка фактов не заменяет полную семантическую
проверку текста. У полностью одинаковых опубликованных условий сохраняется
идентификатор профиля — отличия в услугах не выдумываются. Развёрнутой внешней версии нет.
