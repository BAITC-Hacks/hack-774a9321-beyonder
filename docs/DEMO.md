`main` (`20013c4`, включая объяснения `7ad595a`). В этом прогоне `OPENAI_API_KEY`

Запустите сервер по [README](../README.md), затем во втором терминале из корня
проекта:

```powershell
.\.venv\Scripts\python.exe scripts/demo.py
```

На macOS/Linux: `.venv/bin/python scripts/demo.py`. При другом порте добавьте
`--base-url http://localhost:8001`. Для одного сценария используйте `--case dense`
(также `rare`, `no-category`, `none`, `december`, `invalid`). Скрипт отправляет
запросы, показывает исход, воронку, карточки, объяснения, причины исключения и
подсказки; проверяет ожидаемые исходы и ID. Фактический прогон завершился:
**PASS: 6 ответов, 0 ошибок**. Все полные запросы и ответы сохранены в
[demo-results.json](demo-results.json). Чтобы переснять ответы с запущенного
backend, выполните `python scripts/demo.py --save docs/demo-results.json`.
При провале проверки файл не перезаписывается.

## Шесть проверенных запросов

Все строки таблицы — `POST /api/match`. Общие поля запроса:

```json
{
  "city": "Алматы",
  "date": "2026-10-10",
  "event_type": "свадьба",
  "category": "Фотограф",
  "budget": 800000,
  "duration": null,
  "language": null
}
```

| Сценарий | Изменение к общему запросу | Исход | Карточки по порядку | Воронка |
| --- | --- | --- | --- | --- |
| `dense`: три фотографа | — | `found` | HK-30583 Леорио; HK-16628 Нобара; HK-53108 Альфонс | 8 → 4 → 4 → 3 |
| `rare`: флористы | `category: Флорист` | `partial` | HK-39372 Тони Тони Чоппер | 2 → 1 → 1 → 1 |
| `no-category`: нет категории в городе | `city: Астана`, `category: Лайв-бэнд` | `no_category_in_city` | Нет | 0 → 0 → 0 → 0 |
| `none`: слишком низкий бюджет | `budget: 1` | `none_match` | Нет | 8 → 4 → 0 → 0 |
| `december`: та же заявка в декабре | `date: 2026-12-12` | `partial` | HK-76268 Сацуки | 8 → 2 → 2 → 1 |
| `invalid`: вне календаря | `date: 2027-01-01` | `invalid_request` | Нет | Нет этапов |

Четыре числа воронки показывают последовательное сужение: **профили этой
категории в городе → свободны в указанную дату → укладываются в бюджет → берут
формат**. Причины в `excluded` могут пересекаться: один профиль может быть
одновременно занят и слишком дорог, поэтому счётчики причин не складываются.

## Что показать жюри

1. **Плотная категория.** При бюджете 800 000 ₸ у всех трёх фотографов разные
   проверяемые объяснения. Леорио стоит 350 000 ₸ (44% бюджета) и единственный
   в тройке берёт также конференции. Нобара стоит 600 000 ₸ (75%) и может быть
   на площадке до 12 ч, когда у остальных максимум 8 ч. Альфонс стоит
   300 000 ₸ (38%); цена помечена как оценочная, он также берёт дни рождения.
   Все трое свободны 10 октября. API вернул `found`, но не скрывает остальных:
   пять записей в `excluded` объясняют, кто занят или не берёт свадьбу.

2. **Редкая категория.** В Алматы всего два флориста. На 10 октября подходит
   Тони Тони Чоппер; синтетический профиль Тихиро Огино (HK-90001) исключён
   с причиной «занят 10 октября». API честно возвращает `partial` и предлагает
   ближайший свободный день Тихиро — 11 октября.

3. **Нет категории в городе.** На запрос «Лайв-бэнд в Астане» сервер отвечает
   `no_category_in_city`: «Эта категория есть в: Алматы». Карточек нет, пул
   воронки равен нулю.

4. **Никто не подходит.** Бюджет 1 ₸ оставляет 0 из 8 фотографов. Воронка
   `8 → 4 → 0 → 0` показывает, где подбор остановился. Все восемь профилей
   находятся в `excluded`; сообщение перечисляет 8 цен выше бюджета,
   4 занятости и 2 несовпадения формата. Подсказка предлагает бюджет от
   300 000 ₸ для Альфонса, который свободен и берёт свадьбы.

5. **Меняется только дата.** Заявка на 12 декабря возвращает одного фотографа —
   Сацуки Кусакабэ, 200 000 ₸, `partial`. Воронка `8 → 2 → 2 → 1` показывает
   резкое сужение по занятости. Все трое из октябрьской выдачи — HK-30583,
   HK-16628 и HK-53108 — есть в декабрьском `excluded` именно с причиной
   «занят 12 декабря». Это подтверждённое объяснение исчезновения, а не
   предположение по разнице двух списков. Подсказки называют 13 декабря для
   Нобары и 14 декабря для Леорио.

6. **Граница данных.** 1 января 2027 сервер возвращает `invalid_request` и
   объясняет, что на эту дату нет календаря доступности. Сценарий запускается
   через API: обычное поле даты в интерфейсе ограничено диапазоном из `/api/meta`.

Тексты в этом документе и сохранённом JSON относятся к режиму шаблонных
объяснений. Если задан `OPENAI_API_KEY`, необязательная редактура может изменить
формулировки, но проверяемые факты, исходы и порядок карточек остаются теми же.

## Свободный текст

Проверен отдельный вызов `POST /api/parse`:

```json
{"text":"Нужен фотограф в Алматы 10 октября на свадьбу, бюджет 800000 тенге"}
```

Он вернул `source: "rules"`, `missing: []`, пустые `notes` и параметры из общего
запроса выше. В `found` для каждого распознанного поля есть значение и фрагмент
исходной фразы, чтобы пользователь мог проверить, что именно понял сервис.
Сценарии основного подбора в `scripts/demo.py` отправляют структурированные
параметры, поэтому их результат не зависит от распознавания текста.
